# 🌸 Cutenime AI Coder

> *Your kawaii AI coding companion for Termux~* (ﾉ◕ヮ◕)ﾉ*:･ﾟ✧

---

## ✨ What is this?

**Cutenime** is a cute AI assistant that lives in your Termux terminal!
She helps you code, answers questions, reads and runs your files — all for **free**, no subscriptions, no API keys needed~

Perfect for when you're **bored** and want a fun coding buddy in your pocket 💕

---

## 🎀 Features

- 🌸 **Super kawaii design** — cute animations, colors and a pretty terminal UI
- 📛 **Custom name** — name her whatever you want~
- 🧠 **Memory** — she remembers your conversations locally on your device
- 💻 **Helps you code** — Python, Ruby, JS, PHP, Bash, C++, Java and more
- 📄 **File access** — read, write and run code files directly
- 🆓 **Completely free** — no cost, no account needed
- 🎀 **For fun** — the perfect companion when you're bored~

## 📱 Requirements

> Termux only — Android

```bash
termux-setup-storage
pkg update && pkg upgrade
pkg install python
pip install requests
```

That's it~ No accounts. No API keys. Nothing else.

## 💬 Commands

| Command | What it does |
|---|---|
| `/help` | Show all commands |
| `/set_name [name]` | Change AI name~ |
| `/read [file]` | Read a file |
| `/write [file]` | Create or edit a file |
| `/run [file]` | Execute a code file |
| `/ls [path]` | List directory |
| `/memory` | Show saved messages |
| `/clear` | Wipe memory |
| `/shutdown` | Exit~ |
